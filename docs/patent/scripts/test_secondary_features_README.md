# YAMLWeave 二级功能测试脚本 - 使用说明

## 概述

该脚本对 YAMLWeave 项目的四个一级功能及其下属二级功能进行自动化验证，提供清晰的可视化输出和详细的测试报告。

## 功能覆盖范围

### 一级功能与二级功能映射：

1. **扫描并插入**
   - 文件扫描与备份输出
   - 锚点解析与 YAML 容错
   - 安全插入与统计反馈

2. **清除日志**
   - 一键清空界面日志
   - 重置日志通道
   - 着色分级保留

3. **导出日志**
   - 导出当前 UI 日志
   - 执行日志归档与检索
   - 统一目录结构

4. **反向生成 YAML**
   - 提取插桩片段
   - 规范聚合与保留格式
   - 后台导出与状态反馈

## 使用方法

### 基本用法

```bash
python test_secondary_features.py
```

### 命令行选项

- `-v, --verbose`: 显示详细的库日志输出
- `--gap-section <秒数>`: 设置一级功能测试间隔时间（默认5秒）
- `--gap-sub <秒数>`: 设置二级功能测试间隔时间（默认2秒）
- `--no-countdown`: 禁用倒计时显示

### 使用示例

```bash
# 使用默认设置
python test_secondary_features.py

# 显示详细日志
python test_secondary_features.py -v

# 设置间隔时间为3秒
python test_secondary_features.py --gap-section 3

# 禁用倒计时显示
python test_secondary_features.py --no-countdown

# 组合使��
python test_secondary_features.py -v --gap-section 2 --no-countdown
```

## 输出特性

### 1. 增强的可视化效果

- **彩色状态指示器**: 使用不同颜色标识测试状态（PASS/FAIL/WARN/SKIP）
- **进度条显示**: 实时显示整体测试进度
- **层次化结构**: 清晰显示一级功能和二级功能的从属关系

### 2. 详细的测试信息

- **开始/结束时间戳**: 记录每个测试的执行时间
- **预期结果说明**: 明确显示每个二级功能的预期结果
- **实际结果详情**: 提供详细的测试数据和状态信息
- **错误诊断**: 失败时提供具体的错误信息和上下文

### 3. 测试间隔管理

- **倒计时显示**: 在测试间隔期间显示动态倒计时
- **进度提示**: 清晰提示下一个测试的内容
- **可控间隔**: 用户可自定义间隔时间或禁用倒计时

### 4. 完整的测试总结

- **统计概览**: 显示总测试数和成功/失败数量
- **失败详情**: 列出所有失败的一级功能
- **成功验证**: 确认成功通过的功能模块

## 日志文件

测试执行时会自动生成日志文件，保存在以下位置：
```
docs/patent/scripts/logs/test_run_YYYYMMDD_HHMMSS.log
```

日志文件包含：
- 时间戳记录的所有输出
- 清理了ANSI颜色代码的纯文本
- 便于后续分析和调试

## 故障排除

### 常见问题

1. **倒计时显示异常**
   - 使用 `--no-countdown` 参数禁用倒计时

2. **颜色显示问题**
   - 确保终端支持ANSI颜色代码
   - 部分Windows终端可能需要额外配置

3. **权限问题**
   - 确保有写入临时目录的权限
   - 确保有创建日志文件的权限

### 调试建议

1. 使用 `-v` 参数显示详细日志
2. 检查生成的日志文件获取更多信息
3. 确认项目依赖正确安装
