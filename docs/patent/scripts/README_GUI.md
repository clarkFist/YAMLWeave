# YAMLWeave 二级功能测试 - GUI增强版

## 概述

这是YAMLWeave二级功能测试的图形界面增强版本，提供了友好的用户界面和丰富的可视化功能。

## 新增功能

### 🎨 图形界面功能
- **实时进度显示**: 带进度条和状态更新的测试界面
- **弹窗通知**: 测试开始、完成和错误通知
- **可视化结果**: 图表展示测试结果分布
- **交互式配置**: 可视化配置测试参数
- **多标签页报告**: 概览、详细结果、图表三种视图

### 📊 测试结果可视化
- **饼图**: 测试通过/失败分布
- **柱状图**: 各功能模块测试统计
- **详细报告**: 树形视图显示所有测试结果
- **成功率统计**: 实时计算并显示测试成功率

### 🔔 ��统通知
- **跨平台支持**: Windows、macOS、Linux
- **测试状态通知**: 开始、进行中、完成通知
- **错误提醒**: 测试失败或异常时弹出通知

## 安装和使用

### 1. 安装依赖

```bash
# 自动安装GUI依赖
python run_gui_test.py --install

# 或手动安装
pip install matplotlib numpy
```

### 2. 运行方式

```bash
# GUI模式（推荐）
python run_gui_test.py

# 命令行模式（原有功能）
python run_gui_test.py --cli

# 或直接运行原版
python test_secondary_features.py
```

### 3. 使用说明

#### GUI模式操作步骤：
1. **启动程序**: 运行 `python run_gui_test.py`
2. **配置测试**: 点击"配置"按钮调整测试参数
3. **开始测试**: 点击"开始测试"按钮
4. **查看进度**: 实时查看测试进度和状态
5. **查看结果**: 测试完成后自动弹出结果窗口

#### 配置选项：
- **一级功能间隔**: 设置主功能模块之间的间隔时间
- **二级功能间隔**: 设置子功能测试之间的间隔时间
- **演示模式**: 启用更长的间隔时间用于演示
- **禁用倒计时**: 关闭倒计时显示
- **详细输出**: 显示更详细的测试信息

## 界面说明

### 主界面
- **标题栏**: 显示当前测试状态
- **进度条**: 显示整体测试进度
- **状态信息**: 实时更新测试状态
- **控制按钮**: 开始测试、配置、查看结果

### 结果报告窗口
包含三个标签页：

1. **概览**: 显示测试统计信息
   - 总测试数
   - 通过/失败数量
   - 成功率

2. **详细结果**: 树形视图显示所有测试
   - 测试项目名称
   - 测试状态（通过/失败）
   - 详细信息

3. **图表**: 可视化展示
   - 饼图：结果分布
   - 柱状图：模块统计

## 技术特性

### GUI技术栈
- **tkinter**: Python标准GUI库
- **matplotlib**: 图表绘制
- **numpy**: 数值计算
- **threading**: 多线程处理（避免界面阻塞）

### 设计原则
- **非阻塞**: 测试在后台线程运行，界面保持响应
- **实时更新**: 测试进度和状态实时反映到界面
- **用户友好**: 清晰的界面设计和操作提示
- **兼容性**: 跨平台支持，自动回退到命令行模式

## 故障排除

### 常见问题

1. **GUI启动失败**
   - 确保安装了matplotlib和numpy
   - 尝试运行 `python run_gui_test.py --install`

2. **通知不显示**
   - 检查系统通知权限设置
   - 某些Linux发行版需要额外配置

3. **图表显示异常**
   - 更新matplotlib版本: `pip install --upgrade matplotlib`
   - 检查系统字体支持

### 回退方案

如果GUI模式出现问题，程序会自动回退到命令行模式：
```bash
# 直接运行命令行版本
python test_secondary_features.py
```

## 开发说明

### 扩展功能
要添加新的GUI功能，可以：
1. 修改 `test_secondary_features_gui.py`
2. 在 `EnhancedSecondaryFeatureTester` 类中添加新方法
3. 更新界面组件和事件处理

### 自定义通知
可以通过修改 `system_notifier.py` 来：
- 添加自定义通知样式
- 支持更多通知平台
- 调整通知显示逻辑
