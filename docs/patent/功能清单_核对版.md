# YAMLWeave 功能清单（核对版）

- 扫描并插入
  - 文件扫描与备份输出：自动扫描项目目录，识别YAML文件，并在执行插入操作前创建原始文件的安全备份
  - 锚点解析与 YAML 容错：智能解析YAML文件中的锚点引用，处理格式错误和语法异常，确保插桩过程的稳定性
  - 安全插入与统计反馈：在指定位置安全插入探针代码，提供实时的插入进度、成功率和错误统计信息

- 清除日志
  - 一键清空界面日志：提供快速清除当前界面显示的所有日志信息的功能，保持界面整洁
  - 重置日志通道：重新初始化日志输出通道，清除缓存和缓冲区，确保后续日志正常输出

- 导出日志
  - 导出当前 UI 日志：将界面中显示的日志内容导出为文件，支持多种格式（TXT、JSON、CSV）
  - 执行日志归档与检索：按时间或项目对日志进行归档存储，提供关键词搜索和过滤功能
  - 统一目录结构：建立标准化的日志存储目录结构，便于管理和查找历史日志文件

- 反向生成 YAML
  - 提取插桩片段：从已插桩的代码中自动提取探针相关的代码片段和配置信息
  - 规范聚合与保留格式：将提取的片段按照标准YAML格式重新聚合，保持原有的缩进和结构
  - 后台导出与状态反馈：在后台异步执行YAML文件生成任务，通过进度条和状态提示反馈执行情况
