## 图片规格要求

### 专利审查要求
- **清晰度**: 确保缩小到2/3时仍清晰可辨
- **字体大小**: 最小16px，关键文字18px
- **边框粗细**: 最少2px，重要元素3px
- **文件格式**: SVG矢量图（首选）+ PNG位图（备用）

### 色彩编码
- **流程图**:
  - 处理节点: #F1F1F1 (浅灰)
  - 决策节点: #F1F1F1 (浅灰)
  - 注释说明: #FEFFDD (浅黄)

- **三级索引图**:
  - 第一层: #E3F2FD (浅蓝)
  - 第二层: #BBDEFB (中蓝)
  - 第三层: #F3E5F5 (淡紫)

## 文件使用说明

### PlantUML源码（source/）
- 可编辑和修改的原始文件
- 支持版本控制和协作开发
- 便于后续图片调整和优化

### SVG文件（svg/）
- 矢量图格式，支持无损缩放
- 专利申请的主要提交格式
- 适合打印和高分辨率显示

### PNG文件（png/）
- 位图格式，兼容性好
- 备用提交格式
- 适合在线查看和预览

## 生成新图片的方法

1. 修改对应的PlantUML源文件
2. 使用命令生成SVG: `plantuml -tsvg filename.puml`
3. 如需PNG格式: `plantuml -tpng filename.puml`
4. 移动文件到对应目录
