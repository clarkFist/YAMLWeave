# 卡斯柯YAMLWeave-C语言自动插桩软件V1.0 功能清单

## 产品基本信息
- **产品名称**: 卡斯柯YAMLWeave-C语言自动插桩软件V1.0

## 软件功能详细说明

### 1. 代码插桩功能
- **传统模式插桩**: 基于锚点直接实现代码插桩插桩
- **分离模式插桩**: 基于外部配置插桩
- **锚点识别解析**: 对锚点的格式进行正则化识别
- **多文件批量处理**: 批量处理文件

### 2. 文件管理功能
- **自动备份机制**: 处理前自动创建原始项目完整备份，确保数据安全
- **结果输出管理**: 插桩后文件保存到独立的带时间戳目录中
- **目录结构维护**: 自动维护源文件的相对路径和目录层次结构

### 3. 配置管理功能
- **配置验证检查**: 自动验证YAML配置文件格式和内容完整性
- **多级配置支持**: 支持测试用例ID、步骤ID、代码段ID三级配置结构

### 4. 用户界面功能
- **项目路径选择**: 提供文件对话框选择待处理的C语言项目目录
- **配置文件选择**: 提供文件对话框选择桩代码配置YAML文件
- **实时进度显示**: 显示文件处理进度和状态信息，提供进度条反馈
- **操作日志输出**: 实时显示处理过程、锚点发现、插桩结果等信息

### 5. 日志记录功能
- **操作日志输出**: 实时显示处理过程、锚点发现、插桩结果等信息
- **统计信息生成**: 生成扫描文件数、成功插桩数、失败文件数等统计
- **错误信息跟踪**: 记录处理失败的文件路径和具体错误原因
